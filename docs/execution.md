# 执行边界

## 工具准入

模型不能创建或注册工具。工具名称、Schema、函数与审批要求由宿主固定提供。
未知工具、Schema 不匹配、重复调用 ID、过大的工具批次都会被拒绝。
Schema 的外部引用不联网加载。

默认逐次审批；未提供审批回调时拒绝执行。用户界面或宿主程序负责确认意图，
不要让模型自己实现批准自己的回调。

## 失败和副作用

- Runtime 不重试模型调用或工具执行；供应商 SDK 的重试由宿主另行配置。
- 同一会话内已使用的调用 ID 不会再次执行。这不是参数级幂等，也不跨进程生效。
- 工具报错、超时或取消时，外部副作用可能已经发生，需要业务方检查实际状态。
- 工具输出超过限制时返回长度错误，不把截断后的无效 JSON 写入历史。
- 中断中的未配对工具请求会补为 `interrupted` 结果，后续对话能看到不确定状态。
- 模型和工具异常文本不直接进入公共结果，避免把异常中的凭据或私有路径带回模型。

## 适用范围

运行时没有 OS 沙箱、文件访问范围约束或网络防火墙。
`requires_approval` 和 asyncio 超时都不能替代宿主级隔离。
只向进程注册可信工具，不向不可信第三方开放 Python 执行入口。

不保存历史时，进程结束后历史丢失。宿主可以导出JSON并在新进程加载聊天记录，
但不提供检查点重放、崩溃恢复、外部副作用去重或恰好执行一次。
LangChain 适配器目前限普通文本和工具调用，遇到需要回传的推理状态会拒绝响应，
不会静默丢弃后继续请求。

## 工作区与保存的数据

工作区工具必须由宿主显式启用，只读选定根目录内的普通UTF-8文件。
路径检查拒绝相对越界、绝对路径、Windows备用流和静态链接；
它不替代宿主级资源隔离，也不能防止另一个进程在检查后恶意替换父目录。
隐藏文件和常见凭据后缀被过滤，不等于所有可读文件都不含敏感信息。

JSON历史只校验结构，不能认证它来自谁。宿主应限制存储访问，必要时加密，
不要直接把任意用户上传的历史视为可信模型上下文。

## 消费者退出

事件流有独立生产任务，最多缓冲32条执行事件。使用`contextlib.aclosing`包住迭代器，
让提前break或调用方取消时能够关闭流、取消生产任务并等待清理。
如果实际执行已经结束而调用方只是不再读取剩余事件，会话保留其实际终态。
